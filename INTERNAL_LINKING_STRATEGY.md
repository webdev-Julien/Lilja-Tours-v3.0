# Internal Linking Strategy for SEO

**Purpose**: This document contains all proposed internal links across all collections (tours_EN, multiday_tours_EN, partner_experiences_EN, blog_articles_EN).

**Instructions**:

- Review each section and DELETE any links you don't want to include
- Once finalized, provide this document back to implement the links
- Links are organized by SOURCE FILE, showing which pages to link TO
- Format: `[Link Text](/path/to/page/)`

**CRITICAL - Frontmatter vs Body Content**:

- **Markdown links ONLY work in MDX body content (after the closing `---`)**
- **Markdown links DO NOT work in YAML frontmatter fields** (title, description, visits, highlights, etc.)
- Links in frontmatter will display as plain text: `[Link Text](/url/)` instead of clickable links
- **ALL links below should be added to body content ONLY**, never to frontmatter fields
- If you need to reference another page in frontmatter text, use plain text without link syntax
